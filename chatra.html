Overview

A classroom system, not a page collection.

The problem

Schedules, assignments, grades, files, and conversations often live in separate tools, forcing people to rebuild context.

The product idea

Use one shared language and one service, while adapting navigation and actions to students, teachers, and administrators.

My contribution

Frontend implementation, product UI, API integration, and system work across the web and mobile clients.

The constraint

Dense workflows had to remain legible while the product expanded into classes, chat, calendar, files, and study tools.

01 · Orientation

See the learning state at a glance.

The web dashboard puts classes, recent activity, and role-specific routes into one visual frame. Users begin with context instead of a feature menu.

02 · Continuity

The same classroom travels with you.

The mobile client keeps the core concepts familiar while respecting a narrower, touch-first surface. Shared API contracts preserve the underlying state.

03 · Focus

One mobile task at a time.

Subjects and classes become focused vertical lists with thumb-sized targets, clear states, and persistent primary navigation.

Product & interaction design

Share the system. Adapt the surface.

Students, teachers, and administrators work with the same classes and content, but their navigation and permissions reflect different responsibilities. Consistent patterns reduce relearning while the role model keeps irrelevant actions out of the way.

01

Persistent context

Class pages keep materials, assignments, results, and communication connected to the learning space they belong to.

02

Visible system state

Loading, permissions, completion, and notification states clarify what changed and what the user can do next.

03

Platform-aware composition

Web supports breadth and parallel information; mobile prioritizes reach, thumb access, and one task at a time.

Implementation

A frontend built around real service boundaries.

Nuxt provides route and application structure, Vue composes the interface, Pinia coordinates shared client state, and Axios connects authenticated flows to the FastAPI service. The current codebase also includes Vitest and Playwright coverage, file preview and sanitization, and study-content rendering.
